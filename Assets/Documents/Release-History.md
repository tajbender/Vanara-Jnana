
# 🌌 **Jnana — Preview1**  
### **Release Date: August 13, 2026**

---

## ✨ **Introduction**
**Jnana Preview1** is the first public step into a new kind of developer workbench — modular, introspective, and visually expressive.  
This release lays the foundation: navigation, workspace layout, telemetry, GitHub and NuGet integration, and the core identity of the Jnana environment.

Preview1 is not about completeness.  
It’s about opening the door.

---

## 🚀 **What’s Included in Preview1**

### 🧭 **Workbench & Navigation**
- 🔀 NavigationService with history + deep‑linking  
- 🧩 Dockable Workbench panels with persistent layout  
- ⚡ QuickLaunchBar for instant access to tools  
- 📐 Shell Panels (left/right/bottom) with dynamic content  

### 📊 **System & Telemetry**
- 🖥️ Live CPU, RAM, GPU telemetry (EMA‑smoothed)  
- 📡 StatusBar indicators for system load  
- 🧪 Diagnostics overlay for internal metrics

- ✍️ Markdown Editor with live preview  
- 🏁 StartPage with dynamic cards

### 🌐 **GitHub Integration (Preview)**
